# Student Learning Portal

A multi-page website made for BSc IT students. It gives students notes, solved assignments, quizzes and useful links in one place, so they can score good marks in practicals and exams without too much stress.

This is my UI/UX project, built using only **HTML and CSS** (a separate external CSS file for each page).

## Pages

| Page | File | What it has |
|---|---|---|
| Home | `Home_Practical.html` | About the portal, why it matters, faculty / notes providers |
| Notes Provider (Faculty) | `prajakta.html`, `annushree.html`, `darshan.html`, `mukesh.html`, `pradeep.html` | Opens when a faculty card on the home page is clicked. Shows the subject, topics and study help |
| Courses | `courses.html` | All 5 subjects with their topics (See more button) |
| Study Materials | `materials.html` | Assignment and notes PDFs for each subject |
| Quiz | `quiz.html` | Choose a subject quiz or the All-in-One quiz |
| Quiz Tests | `quiz-wt.html`, `quiz-cpp.html`, `quiz-automations.html`, `quiz-coa.html`, `quiz-dm.html`, `quiz-all.html` | Multiple choice questions for each subject |
| Student Resources | `resources.html` | YouTube links for each subject and an AI helper section |

## Features

- 5+ connected pages with the same menu on every page
- Separate external CSS file for each page
- Clickable faculty cards that open a page for that faculty member
- "See more" and "View" dropdown boxes on the courses, materials and resources pages
- Quiz page with 6 test cards (5 subjects and 1 All-in-One)
- Dark blue and gold colour theme
- Layout adjusts for mobile screens

## Technologies Used

- HTML5
- CSS3 (external stylesheets)

## How to Run

1. Download or clone this repository.
2. Keep all the files in the same folder.
3. Open `Home_Practical.html` in any browser.
